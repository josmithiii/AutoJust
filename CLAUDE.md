# AutoJust — canonical repo

This is the canonical AutoJust repo (public: github.com/josmithiii/AutoJust).
A frozen snapshot exists at `/l/ajst` (= `Effects/AutoJust/` inside
`jos-juce-plugins`); it keeps its commit history but is not updated.
All AutoJust development happens here.

Quick build: `make help` lists targets. Common ones:
`make ajr` (release standalone), `make ajro` (build + open), `make tests`,
`make install` (AU + VST3 to `~/Library/Audio/Plug-Ins/`).
